# 🏎️ ZHUZHGO Racing Team — Официальный сайт гоночной команды

Адаптивный многостраничный сайт, разработанный с нуля: от проектирования интерфейсов до технической оптимизации под поисковые системы.

## 📌 Основной функционал и особенности
- **Адаптивная верстка:** Корректное отображение на всех устройствах (десктопы 1920px, планшеты, мобильные телефоны).
- **SEO-оптимизация:** Проработанные мета-теги (Title, Description), строгая иерархия заголовков ($H_1 \to H_6$), семантическая разметка.
- **Микроразметка:** Внедрена разметка Schema.org (Organization, BreadcrumbList) в формате JSON-LD и Open Graph для социальных сетей.
- **Производительность (Core Web Vitals):** 
  - Конвертация всех изображений в современный формат WebP.
  - Использование векторных иконкок SVG.
  - Внедрение отложенной загрузки (`loading="lazy"`).
- **Серверная оптимизация (.htaccess):** Настроено сжатие (Brotli/Gzip), кэширование статики через `mod_expires`, защита от хотлинга и блокировка вредоносных ботов.
- **Аналитика:** Интеграция Яндекс.Метрики и Яндекс.Вебмастера с настроенными целями.

## 🛠 Технологии
- HTML5, CSS3, JavaScript (Vanilla JS)
- Apache, .htaccess, Git
